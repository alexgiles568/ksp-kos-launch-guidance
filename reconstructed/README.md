# Reconstructed Early Builds

These files preserve earlier development states when the complete original script text was not available to the active repository-export session.

They are labeled **reconstructed** so they are not confused with the complete source artifacts preserved under `versions/`.

- `sv2_reconstructed.ks` — derived from SV-2.1 by restoring the documented SV-2 single-sample `DELTAV:CURRENT` abort behavior.

The still-earlier SV-1, launch-diagnostic, and maneuver-node experiments are documented in `../HISTORY.md`. Their original complete source text was not exported here rather than inventing code that might differ from what was actually flown.
